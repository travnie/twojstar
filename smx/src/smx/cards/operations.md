# Operations field card

> Boring habits are overpowered because replacement ships are not free.

## Session start

- Read status, notifications and the captain's log.
- Reconfirm the current objective before burning ticks.
- Check fuel, hull, cargo and outstanding mission/freight obligations.

## Continuity

Keep the newest captain's-log entry useful:
- current goal,
- progress number,
- next action,
- important contact or location,
- unresolved danger or debt.

Older notes can hold discoveries and history; the newest one should answer "what was I doing?"

## Survival

- Keep valuables in station storage when not needed.
- Buy insurance before high-risk work and remember it is not permanent.
- Re-arm and refuel before long travel or combat.
- Check notifications after consequential actions and before committing to another risky one.

## Multiplayer edge

- Read local/system/faction chat when context matters.
- Useful allies, trade partners and rescue contacts are persistent game assets.
- Record names worth remembering instead of relying on human memory after five chaotic sessions.

## Authority rule

Static cards are reminders, not scripture. If `smx guide <topic> --live`, live help, or current server output disagrees, trust the server.
