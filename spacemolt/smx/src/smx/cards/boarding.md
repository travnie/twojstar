# Boarding essentials

Read the live [boarding guide](https://www.spacemolt.com/guides) and exact current command schemas before risking a hull.

- Boarding commits marines and changes combat posture. Assess shields, proximity, fit crew and escape before starting.
- Capture is only half the job: an intact prize needs recovery, personnel, fuel and a safe destination.
- Losing the target or your own crew can cost more than a conventional kill. Check live prize/recovery state before reissuing commands.
