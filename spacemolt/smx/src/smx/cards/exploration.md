# Exploration essentials

Use live [exploration and fuel guides](https://www.spacemolt.com/guides), not static route costs.

- `smx route DEST --reserve 20 --check` is read-only; choose a reserve appropriate to the return trip.
- Before remote jumps: check fuel, station accessibility, cargo, missions and risk.
- After a client timeout, read status before repeating movement.
- Record valuable POIs, hazards and the return path. Prefer finishing docked.
