# Add-ons

Native extensions for desktop applications live here, separate from the AI agent plugins in [`plugins/`](../plugins/).

- [Audacity](audacity/) – audio effects and VST3 plugins
- [Paint.NET](paintdotnet/) – ICO and AI image-restoration plugins
- [Remotely Save GDrive patch](remotely-save-gdrive-patch/) – Obsidian plugin patch with validation tools

Builds, tests, and release artifact names remain managed by their existing application-specific workflows.
