# Storage workflows

This consolidates Google's `google-cloud-storage-basics` and `google-cloud-storage-bucket-architect` skills.

## New bucket

Identify workload and data sensitivity, confirm project/geography, choose location, class or Autoclass, uniform bucket-level access, public access prevention, recovery, retention, encryption, and lifecycle. Check constraints and name availability read-only. Present the plan and requested provisioning form. Create only when the request already authorizes creation or after confirmation.

## Existing storage

Route uploads, downloads, listings, metadata, lifecycle, signed URLs, transfers, and object management through Storage MCP where possible. Keep listings bounded. Retrieve current Storage docs instead of carrying a static command cookbook.
