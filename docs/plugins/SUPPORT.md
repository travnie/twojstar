# Support: twojstar plugins

- **Bugs and requests:** open an issue at [github.com/travnie/twojstar/issues](https://github.com/travnie/twojstar/issues). Name the plugin and its version, and say which app you use it in (Claude, ChatGPT or Codex).
- **Security problems:** report them privately through [GitHub security advisories](https://github.com/travnie/twojstar/security/advisories/new), not in a public issue.
- **Connected services:** for account or outage problems with a connected service (Cloudflare, GitHub, Google, OpenAI, SpaceMolt, Desktop Commander, or the Anthropic, xAI, MCP and ACP documentation servers), contact that service's operator. The plugins run no servers of their own; [Privacy](PRIVACY.md) lists each plugin's services.
- **Documentation:** each plugin's `README.md` describes what it contains, what it connects to and how to sign in: see [`plugins/`](https://github.com/travnie/twojstar/tree/main/plugins) and, for Docbench, [`benches/docbench/plugin/`](https://github.com/travnie/twojstar/tree/main/benches/docbench/plugin).
